# 공공데이터 API 연동 가이드

대입정보포털 어디가(adiga.kr)는 공개 API를 제공하지 않습니다.
대신 **공공데이터포털(data.go.kr)** 에서 한국대학교육협의회 대학알리미 API를 활용할 수 있습니다.

## 1. 활용 신청

1. [공공데이터포털](https://www.data.go.kr) 회원가입
2. 아래 API 활용 신청 (자동 승인)

| API | URL | 제공 데이터 |
|-----|-----|-------------|
| 대학알리미 대학기본정보 | https://www.data.go.kr/data/15037507/openapi.do | 대학 목록, 공시년도 |
| 대학정보공시 학생현황 | https://www.data.go.kr/data/15037346/openapi.do | 신입생 경쟁률, 충원율 등 |

## 2. 서비스 키 발급

- 마이페이지 → 인증키 발급
- **일반 인증키(encoding)** 또는 **일반 인증키(decoding)** 사용
- 발급받은 키를 `.env`에 설정:

```
DATA_GO_KR_SERVICE_KEY=발급받은_서비스키
```

## 3. 트래픽

- 개발계정: 1,000건/일
- 운영계정: 활용사례 등록 시 증가 가능

## 4. 제공 데이터

- **정원내 신입생 경쟁률** (학과별 X:1)
- 신입생 충원율, 입학전형 최종 등록률 등
- (등급컷 50%/70%는 API로 제공되지 않음 - 어디가 웹에서만 확인 가능)

## 5. API 연동 확인

- 백엔드 `.env`에 `DATA_GO_KR_SERVICE_KEY` 설정 후 서버 재시작
- 목표대학 탭에서 "공공데이터 경쟁률 조회" 버튼이 표시되면 연동 완료

## 6. 문제 해결

### resultCode undefined / 조회 실패

- **에러 응답**: API가 `OpenAPI_ServiceResponse` 형식의 에러를 반환하는 경우, 서버 로그에 에러 메시지가 출력됩니다.
- **서비스키**: 일반 인증키(decoding) 사용 시 `.env`에 **디코딩된 키**를 그대로 넣습니다. 일반 인증키(encoding)는 이미 인코딩된 값입니다.
- **활용신청**: 대학기본정보(15037507)와 학생현황(15037346) **둘 다** 활용 신청해야 합니다.
- **schlId 폴백**: 대학 목록 API 실패 시 서울대/연세대/고려대 등 주요 대학은 내장 매핑으로 조회를 시도합니다.

### 디버그 모드

```
DEBUG_PUBLIC_DATA=1
```

환경변수 추가 후 재시작하면 API 파싱 구조가 로그에 출력됩니다.
